# ⚡ Neon Portfolio – Futuristic Cyberpunk Website  
### Live Demo: **https://salahuddingfx.github.io/Neon-Portfolio/**  

A cyberpunk-themed interactive portfolio featuring neon lighting, hologram effects, custom cursor physics, form submission, theme switching, and highly polished animations.

---

## 🚀 Features

### ⚡ Cyberpunk UI System
- Neon gradients  
- Glow edges  
- Animated hologram beam  
- Floating neon particles  

### 🖱️ Custom Cursor Engine
- Dual cursor (ring + dot)  
- Smooth follow physics  
- Hover enlarge effect  

### 🎬 Advanced Motion System
- Intro loading animation  
- Section reveal effects  
- Shimmering neon texts  
- Animated timeline & carousel  

### 🌙 Light & Dark Theme
- CSS Variables  
- Auto-Save in localStorage  
- Animated toggle button  

### 📬 Fully Functional Forms
- Contact form  
- Hiring form  
- Formspree backend  
- Success & error alert system
